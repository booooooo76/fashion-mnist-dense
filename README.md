# fashion-mnist-dense

Навчена повнозв'язна нейронна мережа (Keras) для розпізнавання предметів одягу з набору Fashion MNIST. Лабораторна робота 2.

## Файл

`fashion_mnist_dense.h5` — модель Keras у форматі HDF5 (архітектура та ваги). Завантажується функцією `tensorflow.keras.models.load_model`.

## Архітектура

| Шар | Нейронів | Активація |
|---|---|---|
| Dense (вхідний, 784 входи) | 800 | ReLU |
| Dense (прихований) | 900 | ReLU |
| Dense (вихідний) | 10 | softmax |

Усього параметрів: 1 357 910.

## Параметри навчання

- оптимізатор: SGD, функція втрат: categorical_crossentropy, метрика: accuracy
- epochs = 125, batch_size = 200, validation_split = 0.2
- набір даних: Fashion MNIST (60 000 навчальних і 10 000 тестових зображень)

## Результат

Точність на тестових даних: **87.22%**.

## Вхідні дані

Модель приймає зображення 28×28 у градаціях сірого, розгорнуте у вектор довжиною 784, тобто масив форми `(1, 784)`.
Для розпізнавання власного зображення його потрібно:
1. перевести в градації сірого й змінити розмір до 28×28;
2. інвертувати кольори (`255 - x`), оскільки в датасеті предмет світлий на темному фоні;
3. поділити значення на 255.

## Класи (порядок виходу моделі)

| № | Клас |
|---|---|
| 0 | футболка |
| 1 | брюки |
| 2 | светр |
| 3 | плаття |
| 4 | пальто |
| 5 | туфлі (в оригінальному датасеті — сандалі) |
| 6 | сорочка |
| 7 | кросівки |
| 8 | сумка |
| 9 | черевики (кісточкові) |

## Приклад використання

```python
from tensorflow.keras.models import load_model

model = load_model('fashion_mnist_dense.h5')
prediction = model.predict(x)   # x — масив форми (1, 784)
```
